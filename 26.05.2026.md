# 26.05.2026 — Changes & New Features

## Bug Fixes & Modernization

- **Multi-display fix** — Shelf now appears on the screen where the cursor is dragging, not always the main display.
- **Deprecated API** — Replaced `NSApp.activate(ignoringOtherApps:)` with the modern `NSApp.activate()`.
- **Swift Concurrency** — Replaced `DispatchWorkItem` + `asyncAfter` with `Task` + `Task.sleep` for the hide timer.
- **`@MainActor`** — `ShelfStore` is now annotated for Swift 6 concurrency correctness.

## New Features

### Image Drop Support
Macshelf now accepts raw images dragged from Preview, Photos, screenshots, and any app that puts image data on the drag pasteboard (TIFF/PNG). Previously only files, URLs, and text were accepted.

### Grouped Drag-Drop
When the user drops multiple files at once, they appear as a single **group item** instead of separate entries.

- Visual: a fanned stack of up to 3 file icons with a count badge (e.g. "3").
- Label: "3 Files" (or "3 Items" for mixed types).
- Drag-out: dragging the group out starts a single drag session carrying all files — the destination (browser upload dialog, Finder, any app) receives every file at once, no repeated drags needed.

**Example:** Select 5 photos on the desktop → drag to shelf → one group appears → drag that group to Facebook → all 5 photos land in the upload picker in one move.

## Accessibility
Added VoiceOver labels and hints to shelf items, the info button, and the Clear All button.

## UI Improvements

### Grip Bar Redesign
- Info **(i)** button moved to the left, quit **(x)** button added to the right.
- Bar height reduced and shifted down with top padding so buttons clear the Liquid Glass corner curves.
- Right-click-to-quit context menu on the drag handle removed.

### Hover Name Reveal
Hovering over any shelf item fades out the truncated label and fades in a dark frosted overlay showing the full file name. Disappears when the cursor leaves.

### Quit Confirmation
Clicking **(x)** shows a native popup menu with a single **"Quit"** option instead of quitting immediately — prevents accidental quits.
